# KAMRULHASAN — Personal Gallery

A cinematic, responsive personal photo portfolio built with lightweight HTML, CSS and JavaScript.

## ✦ Highlights

- Premium dark visual system
- Responsive mobile-first layout
- Full-screen cinematic photo viewer
- Keyboard-friendly interactions
- Reduced-motion support
- PWA manifest + offline caching foundation
- Custom SVG brand favicon
- Zero framework dependencies

## 🚀 Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## 🌐 GitHub Pages

This repository is designed for static hosting. Enable **Settings → Pages** in GitHub and publish from the `main` branch.
